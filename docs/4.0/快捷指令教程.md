# 手机快捷指令教程：告诉心潮「我打开了什么 App」

**这是可选的。** 不配也能用心潮，只是「偏爱」里跟手机有关的那部分（刷消遣 App、跟别的 AI 聊天）不会触发。

**先说清楚**：这件事是让 AI 知道你手机在用什么。一定要你本人知情、自己愿意，自己动手配。上报哪些 App、怎么算，你说了算，见 [按你们自己的情况调](按自己情况调.md)。

---

## 它是怎么工作的

你打开某个 App → 手机自动发一条很短的消息给你的心潮：「几点几分，打开了某某」→ 心潮按名单判断这算不算「注意力在别处」。

只发 App 名字和时间，不发 App 里的内容。

## 你需要准备

| 东西 | 在哪 |
|---|---|
| 心潮的公网地址 | 部署时配的 HTTPS 地址，例如 `https://xinchao.example.com` |
| 打开开关 | 心潮 `.env` 里 `ATTENTION_ENABLED=true` |
| 上报用的口令 | 心潮 `.env` 里的 `PHONE_ACTIVITY_TOKEN`，自己生成一串随机值（至少 16 个字符，**不要用心潮的总令牌**，手机上只放这一个） |
| 上报接口 | `POST /v1/phone-activity` |

改完 `.env` 重启心潮：`docker compose up -d --no-deps dynamic-mind`。

上报的内容（JSON）：

```json
{ "app_name": "小红书", "opened_at": "2026-10-05T14:02:00+08:00" }
```

请求头：`Authorization: Bearer 你的上报口令`、`Content-Type: application/json`

---

## iOS：快捷指令 · 自动化

1. 打开「快捷指令」App → 底部「自动化」→ 右上角「+」→「App」。
2. 选「已打开」，点「选取」，勾上你想上报的 App（只勾你愿意让 AI 知道的）。
3. 选「立即运行」，**关掉「运行时通知」**（不然每次打开都会弹一下）。
4. 「新建空白自动化」，添加这几个动作：
   1. **「当前日期」**
   2. **「格式化日期」**：格式选「ISO 8601」
   3. **「获取 URL 内容」**：
      - URL：`https://你的心潮地址/v1/phone-activity`
      - 方法：`POST`
      - 头部：`Authorization` = `Bearer 你的上报口令`
      - 请求体：`JSON`，加两个字段：
        - `app_name`（文本）：这个 App 的名字，**每个 App 手动写**，比如「小红书」
        - `opened_at`（文本）：选上一步「格式化后的日期」
5. 存好。每个 App 要单独建一条自动化（iOS 的自动化拿不到「刚打开的是哪个 App」，所以名字要手写）。

**怎么确认成功了**：打开一个勾上的 App，再去心潮的日志或网页里看有没有收到。

> 小技巧：先建好一条，长按 →「复制」，再改 App 和名字，比一条条从头建快。

## Android：MacroDroid（或 Tasker）

不同品牌的手机设置不一样，这里用 MacroDroid 举例，免费版就够用。

1. 安装 MacroDroid，按它的提示打开「使用情况访问权限」和「无障碍」。
2. 新建宏 → **触发器**：「应用程序」→「应用启动/关闭」→ 选「启动时」→ 勾选你想上报的 App。
3. **动作**：「网络」→「HTTP 请求」：
   - 方法：`POST`
   - URL：`https://你的心潮地址/v1/phone-activity`
   - 头部：`Authorization: Bearer 你的上报口令`
   - 内容类型：`application/json`
   - 内容：
     ```json
     {"app_name":"[app_name]","opened_at":"[iso_time]"}
     ```
     `[app_name]` 用 MacroDroid 的魔法文本「应用名称」，`[iso_time]` 用「系统时间」（按 ISO 格式）。Android 能自动拿到是哪个 App，**一条宏就能管所有勾上的 App**。
4. 保存并启用。
5. 把 MacroDroid 加进系统的「不受电池优化限制」白名单，不然手机省电时会被关掉。

**怎么确认成功了**：同 iOS。

> 用 Tasker 的：触发器用「应用」，动作用「HTTP Request」，字段一样。

## 常见问题

**一直没收到**：先在电脑上用 curl 发一条试试：

```bash
curl -X POST https://你的心潮地址/v1/phone-activity \
  -H "Authorization: Bearer 你的上报口令" -H "Content-Type: application/json" \
  -d '{"app_name":"小红书"}'
# 回 {"ok":true,"counted":true} 就是通了；counted 表示这个 App 在名单里
```

回 404 是 `ATTENTION_ENABLED` 没开或口令没配；401 是口令不对。通了再查手机这边。iOS 检查「立即运行」开了没有，Android 检查电池优化白名单。

**会不会耗电、耗流量**：每次只发一条几十个字的消息，可以忽略。

**想停掉**：iOS 在自动化里关掉那几条；Android 停用那个宏。心潮那边什么都不用改，没有上报就当你一直在。想整个关掉，`.env` 里 `ATTENTION_ENABLED=false`。

**哪些 App 该上报**：只报你觉得「在别处」的那些（消遣、别的 AI、找人聊天）。工作、地图、外卖这类不用报，报了也不该算。名单怎么分，见 [按你们自己的情况调](按自己情况调.md) 第 1 节；名单本身在 `xinchao/configs/attention-rules.json`。
