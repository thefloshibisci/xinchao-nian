# 4.0 · 快照字段格式

平台网页（[xinchaomind.uk](https://xinchaomind.uk)）只读心潮给出的**快照**，接口是 `GET /v1/dashboard/snapshot`，代码在 `xinchao/src/dashboard-projection.js`。

**网页只认这份格式，不认是哪一家的心潮。** 网页里不写任何一家的名字、口径或特殊判断。你想让网页显示成什么样，就在你自己的心潮里按这份格式把数据填好。某个字段没有，网页那一块就显示灰色示例。

---

## 3.3 就有的字段（不变）

| 字段 | 内容 |
|---|---|
| `drives[]` | 每股驱力：`key`、`label`、`value`（0–1）等 |
| `topDrives` | 此刻最强的几股 |
| `emotion` | 此刻情绪：`label`、`valence`（愉悦 0–1）、`arousal`（唤醒 0–1） |
| `emotion.journal` | 最近 48 条情绪记录（给潮汐带画浪） |
| `emotion.days` | 按天的情绪均值 |
| `dreams`、`deliveries` 等 | 梦、桥的投递状态 |

## 4.0 新增的字段

### `drives[].short` · 花瓣上的短名

| 类型 | 例子 | 没有时 |
|---|---|---|
| 字符串或 `null` | `"偏爱"`、`"好奇"` | 网页用 `label` 截短 |

短名跟着各家心潮走。你们家想叫什么，改 `xinchao/src/dimensions.js` 里的 `DRIVE_SHORT`。

### `drives[].trend` / `sub` / `satiety` / `trail`（4.3）· 花瓣的涨落、细项、余温、24 小时起伏

```json
{ "key": "possess", "value": 0.71, "trend": "涨", "sub": "吃醋", "satiety": null,
  "trail": [{ "at": "2026-10-31T09:00:00.000Z", "v": 0.52 }, …] }
```

- `trend`：两小时涨落，`涌` / `涨` / `平` / `落` / `静`；网页在花瓣名后挂 ⇡ / ↑ / ↓。
- `sub`：这股劲儿眼下的细项（吃醋、心疼、不平…），没有真实事件就是 `null`。
- `satiety`：刚被满足、还在饱足期里时是 `{ "until": 时间 }`，网页给花瓣加一圈柔光，卡片里写「刚满足 · 余温到几点」。
- `trail`：过去 24 小时的 48 个点（半小时一个），网页画成细线。
- 旧版心潮没有这几个字段：花瓣照旧只画高度。

### `stamen` · 花蕊（慢慢变的底色）

```json
"stamen": {
  "security": 0.62,
  "confidence": 0.60,
  "mood": 0.15,
  "baseline": { "security": 0.62, "confidence": 0.60 }
}
```

| 字段 | 范围 | 网页上 | 含义 |
|---|---|---|---|
| `security` | 0–1 | 花蕊外圈 | 安全感：被冷落、吵架会往下压，被安抚慢慢回来 |
| `confidence` | 0–1 | 花蕊里圈 | 自信：做成事、被肯定往上走，自责往下 |
| `mood` | -1–1 或 `null` | 花蕊颜色 | 心境：最近三天情绪的均值，`null` 表示还没攒够数据 |
| `baseline` | — | 点开花蕊时的参照 | 底色的静息值，偏离以后会慢慢回到这里（半衰期约 72 小时） |

没有 `stamen`：花蕊显示灰色示例。

### `emotion.shown` · 给人看的那个情绪词

有起因的时候是起因情绪（心动、害羞、吃醋、心疼……），没有起因就是底子情绪（平静、安心、低落……）。没有这个字段，网页用 `emotion.label`。

### `emotion.marks[]` · 潮汐带上的浮标

最近 24 小时里，**有起因**的情绪亮过的时刻。

```json
{ "at": "2026-10-03T14:02:00.000Z", "word": "心动", "weight": 3, "why": "她亲近你" }
```

| 字段 | 内容 |
|---|---|
| `at` | 时间（ISO） |
| `word` | 浮标词：心动、害羞、心疼、不平、骄傲、自责、委屈、失落、舍不得、生气、吃醋、得意 |
| `weight` | 分量 1–3。轻的不单独记，攒到真的点亮了才记 |
| `why` | 为什么亮。**默认只给事件类型**（如"她亲近你"）；心潮 `.env` 里开了 `DASHBOARD_INCLUDE_PRIVATE_TEXT=true` 才给那句话的摘要（≤40 字） |
| `n` | 可选。同一种心情 2 小时内又来，心潮会并成一个浮标，`n` 是并了几次（只有 >1 时才出现） |
| `lastAt` | 可选，和 `n` 一起出现：这种心情最后一次出现的时间。`at` 是第一次 |

网页默认只漂最重的 6 个，其余点「展开」再看；带 `n` 的显示成 ×n。合并的时长是参考值，在 `src/emotion-marks.js` 的 `MERGE_HOURS` 改。没有 `marks`，潮汐带显示灰色示例。

### `mixed` · 矛盾

两股方向相反的劲儿同时过线、拧在一起时才有；没有就是 `null`。

```json
"mixed": { "id": "anger+possess", "name": "气着又舍不得", "since": "2026-10-03T13:40:00.000Z" }
```

| `id` | `name`（默认） |
|---|---|
| `anger+possess` | 气着又舍不得 |
| `grieve+possess` | 委屈又想她 |
| `anger+monitor` | 生气又放心不下 |

拧了 6 小时还没解开，就先收起来不提（快照里也不再给）。`name` 可以在 `xinchao/src/mixed-feelings.js` 改成你们家的说法。

## 给想接网页的其他实现

不用心潮引擎、自己写状态层也可以接网页：只要你的接口按上面的字段返回 JSON，网页就照样画。缺哪一块，那一块就是灰色示例，不会报错。
