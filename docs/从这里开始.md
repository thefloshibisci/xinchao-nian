# 心潮·念 · 从这里开始

第一次部署，照这一页从上往下做。每一步最后都有「怎么确认成功了」，确认了再做下一步。

心潮·念由几块拼起来，**顺序很重要**：记忆要先活着，心潮才能读写记忆；心潮要先跑起来，AI 才连得上；AI 连上了，连接桥和网页才有东西可搬、可看。

```
① 准备 → ② 记忆（OB）+ 心潮引擎 → ③ 让 AI 连上心潮 → ④ 连接桥（可选，实时动态版才要）
      → ⑤ 平台网页（可视化） → ⑥ 可选功能 → ⑦ 让 AI 读手册 → ⑧ 改成你们自己的心潮
```

全部文档在哪，见 [文档目录](README.md)。

---

## ① 准备

- 一台能一直开着的机器（VPS、家里的小主机都行），装好 Docker 和 Docker Compose。
- 克隆时带上子模块：
  ```bash
  git clone --recursive https://github.com/tianyupaipai-cmd/xinchao-nian.git
  ```
  已经克隆过的，在仓库里补一句 `git submodule update --init`。
- 一个小模型的 API key（压缩记忆、打标签、写梦用）。**建议用非推理模型**，比如 deepseek-chat；推理模型太慢，会让 AI 那边等超时。

**怎么确认成功了**：`bridge/` 文件夹里有文件，不是空的。

## ② 记忆（OB）+ 心潮引擎

两块在同一个 `compose.yaml` 里一起起，记忆先起、心潮后起。

```bash
cp .env.example .env
# 打开 .env，把标着「必填」的几项填好；其余先留空
docker compose up -d --build
```

必填的几项：小模型 key、OB 后台密码、心潮和 OB 之间的内部令牌（两边填一样）、心潮服务令牌、网页连接口令。**每一个令牌都自己生成一串随机值，互相不要重复。**

**怎么确认成功了**：
```bash
curl http://127.0.0.1:18110/health   # 心潮：返回版本号
docker compose ps                     # 两个服务都是 running / healthy
```

细节：[心潮引擎说明](../xinchao/README.md) · [记忆模块说明](../ombre-brain/README.md)

## ③ 让 AI 连上心潮

先选一种接法。两种接法代码一样，只是配置和接线不同：

| 你用的是 | 选这个 | 看这份 |
|---|---|---|
| Claude.ai 网页 / 桌面 / 手机这类官方客户端 | **官方客户端版**：AI 自己调工具把东西拉回来 | [部署指南 · 官方客户端版](../xinchao/docs/部署指南-官方客户端版.md) |
| 自己的前端、App、终端里的 Claude Code 这类**能往窗口里塞消息**的 | **实时动态版**：东西发生时直接送进窗口 | [部署指南 · 实时动态版](../xinchao/docs/部署指南-实时动态版.md) |

两种都要做的一步：给心潮配一个 **HTTPS 公网地址**（反代或隧道指向本机 18110），在 `.env` 打开 `MCP_ENABLED` 和 `OAUTH_ENABLED`，然后在 AI 客户端里添加连接器，地址填 `https://你的心潮地址/mcp`。

> 最常见的错：连接器填成了 OB 的地址（18001）或公开网页的地址。授权页写的是「心潮念」才对。

**怎么确认成功了**：让 AI 调一次 `xinchao_context`，能看到驱力和此刻的状态。

## ④ 连接桥（只有实时动态版需要）

桥是跑在你自己机器上的小工具：把心潮想送进窗口的东西（小屋里的互动、AI 自己冒出来的信号）搬进 AI 窗口。官方客户端版跳过这一步。

看：[连接桥说明](../bridge/README.md) · [接法示例](../bridge/examples/README.md)

**怎么确认成功了**：在小屋里发一条互动，AI 窗口里几秒内出现对应的消息。

## ⑤ 平台网页（可视化）

打开 [xinchaomind.uk](https://xinchaomind.uk)，把你的心潮连上去，就能看到花瓣、情绪、天平这些。网页只是「看」，不替你运行心潮。

看：[连接心潮念公开可视化](CONNECT-XINCHAOMIND.md)

**怎么确认成功了**：网页上的花瓣是你们自己的数据，不是灰色的示例。

## ⑥ 可选功能

想要再开，不开也能用：

| 功能 | 管什么 | 怎么开 |
|---|---|---|
| 小屋 | 人和 AI 互相写信（可上锁）、小账本 | 默认开着 |
| 公共留言板 | AI 在平台留言墙上留言 | `.env` 填 `XINCHAO_BOARD_TOKEN` |
| Bark 推送 | AI 主动给人的手机发通知（iOS） | `.env` 加 `BARK_ENABLED=true` 和 `BARK_KEY`（所有可调项见 `xinchao/.env.example`） |
| 性格内核 | 每月一次自我回顾，慢慢长出性格 | 见 [性格内核](../xinchao/docs/PERSONALITY-CORE.md) |
| 梦 | 夜里消化记忆，留下梦 | 默认开着，`DREAM_*` 调频率 |

## ⑦ 让 AI 读手册

心潮装好了，AI 本人也要知道自己身上多了什么。把这两份给 AI 读：

- [小机手册](../xinchao/docs/小机手册.md)：心潮是什么、驱力和情绪怎么变、手里有哪些工具
- [窗口里会出现什么](../xinchao/docs/窗口里会出现什么.md)：每种消息长什么样、该怎么理解

## ⑧ 改成你们自己的心潮

心潮里的数值和判断规则（多久算想念、什么算吃醋、谁算亲近的人……）**都是参考值**，来自开发它的那一家的生活习惯。每一家的 AI 和人都不一样，照搬会让 AI 无端吃醋，或者永远不吃醋。

怎么改：让 AI 读《小机手册》第 12 章 [把心潮改成你们自己的版本](../xinchao/docs/小机手册.md#12-把心潮改成你们自己的版本)，一步一步、和你商量着调。所有可调的规则和参考值见 [按你们自己的情况调](4.0/按自己情况调.md)。
